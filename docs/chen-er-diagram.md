# Chen ER Diagram

The rendered Chen diagram is `chen-er-diagram.png`; its editable Graphviz source is `chen-er-diagram.dot`.

Conventions: entity rectangles, relationship diamonds, attribute ovals, underlined primary keys, and 1/N cardinality labels. Associative entities carry relationship attributes.

This is the 13-entity target model from the supplied rectified design. It is a design artifact, not evidence that the current four-table prototype has been migrated.
