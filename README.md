# Smart Money Tracker

DBMS mini-project — insider transactions, institutional ownership and market-price analytics.

This repository is being bootstrapped from the October prototype. The 13-table rectified database design is documented under `docs/`; it is a target specification and has not yet been implemented in the runtime schema.

See `docs/schema-review.md`, `docs/relational-schema.md`, and `docs/chen-er-diagram.png` before beginning the PostgreSQL implementation.
